# Changelog

## [1.0.1] - 2026-11-25

- Added the stone brick recipe icon to the datapack and README.

## [1.0.0] - 2026-11-25

- Place two identical slabs side by side to recover one matching block in your inventory grid or crafting table.
- Choose the ZIP for your Java version from 1.13 through 26.3. A separate preview covers 26.4 Snapshot 1 through Pre-Release 1.
- For Java 1.21.11, download `Slabs2Blocks-1.20.2-26.3.zip`. All 61 recipes were crafted and checked on a vanilla 1.21.11 server.
- Install one version ZIP directly in your world's `datapacks/` folder. If you download the All-Versions bundle, extract it first.
